# 시스템 아키텍처

## 문서 목적

작은 프로젝트에서 현재 시스템의 핵심 구조를 한 문서로 관리하기 위한 통합 템플릿입니다. 규모가 커지면 [아키텍처 안내](README.md)의 분리 기준에 따라 관점별 문서로 나눕니다.

## 언제 수정하는가

- 시스템 경계, 주요 구성 요소, 실행 흐름, 배포 또는 데이터 구조가 바뀔 때
- 품질 목표, 공통 설계 원칙, 알려진 위험이 달라질 때
- 관련 ADR의 결정이 현재 구조에 반영될 때

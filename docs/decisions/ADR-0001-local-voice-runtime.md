# ADR-0001: 외부 AI API 없는 로컬 음성 런타임

## 맥락

사용자의 외부 AI API 불사용 방향과 기존 로컬 음성·서빙 자산 활용 요청.

## 결정 기준

- 사용자 방향·오프라인 실행·한국어 양방향 대화 충족
- 기존 프로젝트 재사용과 시스템 책임 경계 유지
- 지연·취소·실패를 검증 가능한 단위로 관리

## 검토한 대안

| 대안 | 장점 | 비용·위험 |
| --- | --- | --- |
| 외부 Realtime/Live API | 음성 세션 구축이 빠름 | 외부 AI API 불사용 요구와 불일치 |
| 로컬 STT·LLM·TTS와 자체 제어기 | 기존 프로젝트 재사용·데이터 통제·모델 교체 가능 | 반향·취소·endpoint·동시 실행 직접 구현 필요 |
| 음성 통합 모델 처음부터 학습 | 음성 표현과 행동을 통합 최적화 가능 | 데이터·학습 자원·평가 비용이 초기 범위 초과 |

## 결정

로컬 STT·LLM·TTS를 연결하고 양방향 대화 제어를 직접 구현. 모델 artifact 최초 확보 이후 핵심 대화·메모·알림은 외부 통신 없이 실행. 승인 범위는 사용자 방향이며 개별 모델·프레임워크 확정 제외.

## 결과

### 긍정적 결과

기존 자산 활용과 로컬 데이터 처리, provider 교체 가능한 구조.

### 부정적 결과와 비용

통합 음성 모델의 억양·감정·동시 발화 이해와 동일한 품질 보장 불가. 구성 요소 간 지연 최적화 필요.

### 후속 작업

- T002 모델·라이선스·성능 기준선, T004 실제 로컬 모델 통합, T006 오프라인 E2E
- 제안 상태의 세부 결정은 해당 구현 결과에 따라 상태 확정

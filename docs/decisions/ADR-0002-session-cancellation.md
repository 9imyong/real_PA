# ADR-0002: 동시 활동과 generation 기반 취소

## 맥락

기존 발화별 처리 구조만으로 출력 중 입력과 늦은 결과 차단을 관리하기 어려움.

## 결정 기준

- 사용자 방향·오프라인 실행·한국어 양방향 대화 충족
- 기존 프로젝트 재사용과 시스템 책임 경계 유지
- 지연·취소·실패를 검증 가능한 단위로 관리

## 검토한 대안

| 대안 | 장점 | 비용·위험 |
| --- | --- | --- |
| 순차 STT → LLM → TTS | 구현이 단순함 | 재생 중 입력·취소·후속 발화 요구 충족 어려움 |
| 프레임 큐와 세션 제어기 | 끼어들기·지연·늦은 결과를 명시적으로 관리 | 동시성·큐 상한·취소 종료 확인의 구현 비용 |
| 오디오를 범용 메시지 브로커로 전달 | 기존 이벤트 인프라 활용 | 왕복·운영 복잡도·취소 및 실시간 지연 부담 |

## 결정

입력·인식·생성·재생 활동을 병렬 관리하는 대화 제어기 제안. session_id·turn_id·generation_id로 취소를 식별하고 실제 playback 확인으로 기억 범위 결정. 도구 operation_id는 별도 수명 유지.

## 결과

### 긍정적 결과

늦은 결과와 새 턴의 분리, 관측과 실패 주입 가능.

### 부정적 결과와 비용

재생 확인·부분 문장 정렬·실기기 AEC 연동 추가 비용.

### 후속 작업

- T003 세션·취소·AEC 구현, T004 provider 취소, T006 끼어들기 지연 검증
- 제안 상태의 세부 결정은 해당 구현 결과에 따라 상태 확정

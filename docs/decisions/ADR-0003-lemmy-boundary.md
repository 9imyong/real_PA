# ADR-0003: Lemmy의 정책·도구·데이터 소유권 유지

## 맥락

실시간 음성 경로 추가 시 업무 규칙 복제와 인증 우회·등록 중복 방지 필요.

## 결정 기준

- 사용자 방향·오프라인 실행·한국어 양방향 대화 충족
- 기존 프로젝트 재사용과 시스템 책임 경계 유지
- 지연·취소·실패를 검증 가능한 단위로 관리

## 검토한 대안

| 대안 | 장점 | 비용·위험 |
| --- | --- | --- |
| Lemmy 기능과 DB를 복제 | 독립 실행 쉬움 | 사용자·권한·업무 규칙 중복과 데이터 불일치 |
| Lemmy 서비스/도구 어댑터 | 기존 기능·정책·데이터 재사용 | 실제 revision·호출 계약·멱등성 점검 필요 |
| 모델이 DB/로봇을 직접 조작 | 연동 경로가 짧음 | 정책 우회·오류 행동·안전 경계 위반 |

## 결정

real-PA는 음성 및 모델 실행을 소유하고 Lemmy 어댑터를 통해 기존 도구 실행. 사용자 인증·권한·DB·행동 상태는 Lemmy 소유. 도구 호출 검증·내구성 중복 방지·실행 결과 조회 경계를 실제 코드 확인 후 확정.

## 결과

### 긍정적 결과

기존 업무 소유권과 회귀 범위 유지, 신규 경로의 점진 도입 가능.

### 부정적 결과와 비용

Lemmy 측 최소 변경 가능성 및 어댑터 호환 검증 필요.

### 후속 작업

- T005 인증·도구·UI 계약 확정, T006 실제 연동·복귀 검증
- 제안 상태의 세부 결정은 해당 구현 결과에 따라 상태 확정

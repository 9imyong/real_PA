# 요구사항: 로컬 실시간 양방향 음성 대화

## 목적과 문제

기존 Lemmy의 발화별 STT → LLM → TTS 흐름을 지속 입력·동시 출력·끼어들기 가능한 대화로 확장.
기존 공개 모델은 로컬 실행하며 음성 전송·대화 제어·취소·기억 정합성은 직접 구현.

## 이해관계자

| 역할 | 필요한 결과 |
| --- | --- |
| 사용자 | 자연스러운 한국어 대화와 수정·중단 |
| 개발자 | 모델 교체 가능한 포트와 재현 가능한 검증 |
| Lemmy 소유자 | 사용자 정책과 도구 실행 권한 유지 |

## 인수 조건

- 호출어로 시작한 세션에서 한국어 후속 대화 10회 수행 가능
- 답변 중 사용자 수정 시 기존 음성 중단 후 수정한 맥락으로 응답
- 이전 턴의 생성 결과가 새 턴의 재생·화면·기록을 오염시키지 않음
- 미재생 내용을 이미 들려준 발언으로 저장하지 않음
- 준비된 모델로 외부 네트워크 차단 상태에서 대화 시나리오 수행
- 헤드셋 검증과 별도로 실제 스피커·마이크 검증 필수

## 범위

### 포함

- 로컬 KWS·VAD·스트리밍 STT·LLM·TTS·대화 제어기
- 반향 제거, 오디오 큐·상태·취소·복구, 한국어 품질 측정
- 모델·샘플 라이선스 및 재현 가능한 artifact 기록

### 제외

- 음성 기반 대형 foundation model의 처음부터 학습
- GPT Realtime과 동일한 감정·억양·응답 품질 보장
- 첫 버전의 여러 사용자 동시 대화와 클라우드 자동 fallback

## 품질과 제약

아래 수치는 초기 개발 목표. 지원 하드웨어 확정 및 T002·T006 측정 전 보장 금지.

| 지표 | 초기 목표 | 측정 기준 |
| --- | --- | --- |
| 첫 음성 지연 | p95 1.5초 이하 | 정답 발화 종료 시각 → 첫 실제 출력 샘플, 로컬 일반 대화·워밍업 후 |
| 끼어들기 중단 지연 | p95 200ms 이하 | 사용자 음성 시작 정답 시각 → 기존 출력 종료 |
| 연속 대화 | 30분 이상 | 버퍼·메모리 제한 유지, 진행 실패·복구 횟수 별도 기록 |
| 거짓 끼어들기 | 10분 자체 재생 중 1회 이하 | 사용자 침묵, 고정 거리·음량·장치 기록 |
| 인식·도구 품질 | T002에서 평가셋과 합격 기준 확정 | 부분 STT와 최종 STT 분리 평가, 확정 전 성능 주장 금지 |

- 성능 표본: 일반 대화 100회, 끼어들기 100회 목표, 원시 시각·p50·p95·실패 수 기록
- 도구 대기 지연은 일반 대화 지연과 분리 보고
- 접근성: 텍스트 입력·자막·명시적 중지 경로 제공 예정
- 최초 다운로드와 의존성 준비는 오프라인 실행 인수 조건의 사전 준비로 허용
- 외부 코드·모델·음성의 사용 권한과 재배포 조건 확인 필수

# 작업 문서 안내

여러 파일이나 모듈을 횡단하거나, 하루 이상 걸리거나, 인수 조건이 여러 개이거나, 다른 사람이 이어받을 수 있는 작업에 사용합니다.

- 진행 중: `active/`
- 완료된 이력: `completed/`
- 새 작업: [작업 템플릿](TASK_TEMPLATE.md)

## 폴더 단독 사용

- **용도:** 소형 프로젝트의 작업 계획·진행 상황·완료 이력 관리
- **준비:** 이 폴더 전체를 프로젝트에 복사하고 `active/`, `completed/` 구조 유지
- **작성 기준:** 아래 문서 작성 스타일과 상태 모델 적용
- **관련 문서:** 프로젝트에 존재하는 기준 문서만 연결, 해당하지 않는 템플릿 항목은 `해당 없음`과 사유 기록

완료된 작업 문서는 현재 시스템 동작의 기준이 아닙니다. 결과로 바뀐 요구사항과 아키텍처를 각각의 기준 문서에 반영해야 합니다.

## 문서 작성 스타일

이 폴더만 복사해도 규약을 참조할 수 있도록 공통 작성 스타일을 함께 제공합니다.

- **기본 문체:** 개조식과 명사형 종결 사용
- **항목 구성:** 항목 하나당 핵심 내용 하나만 기술
- **의미 보존:** 조건·주체·예외 생략 금지, 필수·권장·허용·금지 구분
- **서술문 허용:** 배경·결정 이유·인과관계 설명에 짧은 서술문 사용
- **형식 선택:** 절차는 번호 목록과 구체적인 행동·기대 결과, 비교는 표, 단순 나열은 글머리표 사용
- **정보 배치:** 목적·적용 범위·핵심 내용을 앞부분에 배치
- **중복 최소화:** 상세 규칙은 기준 문서에서 관리하고 다른 문서에서는 요약과 링크 제공
- **템플릿 안내:** 작성 지침과 실제 본문 구분, 프로젝트 적용 시 불필요한 안내 제거

### 적용 범위

- 이 폴더의 새 문서와 기존 문서의 수정 부분부터 적용
- 기존 문서 전체의 일괄 전환은 필수 아님, 가독성 개선이 필요한 파일부터 순차 정리
- 문체 변경 시 기존 규칙의 의미와 의무 수준 유지
- 전체 저장소에서 사용 시 공통 문서 운영 정책과 함께 적용, 공통 작성 스타일 변경 시 이 절의 일치 여부 확인

### 작업 문서 예시

- **목표:** 작업 목록의 상태별 조회 기능 제공
- **범위:** 상태 필터와 결과 목록 구현
- **인수 조건:** `Done` 선택 시 완료된 작업만 표시
- **검증 결과:** 상태별 조회 테스트 통과
- **후속 작업:** 해당 없음

## 상태 모델

| 상태 | 의미 |
| --- | --- |
| `Proposed` | 제안되었으나 착수 준비 전 |
| `Ready` | 범위와 요구사항이 정리되어 착수 가능 |
| `In Progress` | 구현 또는 검증 진행 중 |
| `Blocked` | 외부 결정이나 조건 때문에 진행 불가 |
| `Done` | 완료 조건과 검증 충족 |
| `Cancelled` | 수행하지 않기로 결정 |

상태 값은 자동화와 검색을 위해 영문 표준값을 사용하고 본문 설명은 한글로 작성합니다.

## Task 작성 여부

다음 중 하나 이상이면 Task 작성을 권장합니다.

- 여러 파일이나 모듈을 횡단합니다.
- 하루 이상 작업이 예상되거나 다른 사람이 이어받을 수 있습니다.
- 인수 조건 또는 검증 단계가 여러 개입니다.
- Architecture, Spec 또는 데이터 마이그레이션이 함께 바뀝니다.
- AI Agent가 여러 단계에 걸쳐 작업합니다.

- **Task 생략 가능:** 한두 파일의 명백한 수정이며 구조·계약·운영 절차에 영향이 없는 경우, 이슈와 변경 요청으로 관리
- **전체 저장소에서 사용 시:** `docs/DOCS_GOVERNANCE.md`의 상세 생성·생략 기준 준수
- **폴더 단독 사용 시:** 이 문서의 Task 작성 여부 기준 적용

## 상태 전환과 완료

일반적인 흐름은 `Proposed → Ready → In Progress → Done`입니다. 진행할 수 없으면 `Blocked`, 수행하지 않기로 하면 `Cancelled`로 변경하고 이유를 진행 기록에 남깁니다. `Done`이 된 문서는 기준 문서 갱신을 확인한 후 `completed/`로 이동합니다.

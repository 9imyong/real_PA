# 작업: 로컬 모델·장치 성능 기준선 확보

## Status

- In Progress, 아래 진행 기록 기준

## Objective

실제 하드웨어에서 실행 가능한 한국어 STT·LLM·TTS 후보와 측정 가능한 합격 기준 확보.

## Context

문서에 기록된 LocalForge 장비·Coder fixture와 음성 프로젝트 경험은 비서 품질·동시 실행 성능의 증거가 아님.

## Scope

- 운영체제·GPU·오디오 장치·런타임 버전 확인
- 공개 모델별 revision·SHA256·라이선스 및 다운로드/오프라인 경로 기록
- STT 부분/최종 전사와 한국어 LLM 응답·도구 인자 평가셋 작성
- STT·LLM·TTS 단독 및 동시 실행 지연·peak VRAM·자원 측정
- AEC 구현 후보·지원 장치·render 참조·WSL 입력 제약 비교
- 한국어 평가 합격 기준·모델 조합·하드웨어 지원 범위 확정

## Out of Scope

- 모델 최초 학습·Lemmy 실제 기능 연결·제품 품질 완료 주장

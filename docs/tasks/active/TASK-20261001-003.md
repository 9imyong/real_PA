# 작업: 지속 오디오 입력·세션·끼어들기 제어 구현

## Status

- In Progress, 아래 진행 기록 기준

## Objective

말하는 중에도 입력을 유지하고 끼어들기로 이전 생성·재생을 종료하는 대화 제어기 확보.

## Context

현재 real-PA에는 런타임 없음. T002의 장치 결과 및 ADR-0002 제안을 구현 기준으로 구체화.

## Scope

- audio capture/playback·AEC 참조 신호·pre-roll·제한 큐 구현
- KWS/VAD·streaming STT 포트 및 부분/최종 전사 구분
- 세션 상태·동시 활동·turn/generation 식별·timeout·유휴 종료 정의
- 취소 신호·task 종료 확인·재생 flush·늦은 결과 필터 구현
- 실제 재생 확인과 중단 범위 기록
- fake provider로 역순·지연·장치 손실·취소 경합 테스트

## Out of Scope

- 실제 로봇 이동·새 음성 foundation model·Kafka 도입

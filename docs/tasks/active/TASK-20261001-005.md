# 작업: Lemmy 권한·도구·화면 연동

## Status

- In Progress, 아래 진행 기록 기준

## Objective

로컬 음성 대화로 Lemmy 메모 조회와 알림 조회·등록 수행, 중복 실행·권한 우회 방지.

## Context

Lemmy에 provider-neutral 도구 정의·사용자 문맥 존재. 실제 revision과 호출 경계는 착수 시 확인 필수.

## Scope

- Lemmy revision·현재 도구 정의·서비스 경계·인증·생체 정책 확인
- real-PA 어댑터와 allowlist·인자 검증·신뢰 문맥 전달 정의
- 메모 조회·알림 조회/등록의 실제 저장 결과 연결
- 내구성 operation_id·상태·중복 방지·timeout 결과 조회 구현
- 도구 취소/완료와 음성 generation 취소 분리
- 자막·대표 상태·결과 화면 이벤트와 기능 플래그·복귀 연결
- Lemmy 회귀·타 사용자 접근·재연결·재시작·동일 키 테스트

## Out of Scope

- 메모 삭제·실제 로봇 이동·외부 통화·Lemmy 전체 복제

# 작업: 실기기·오프라인·Lemmy 종단 간 인수

## Status

- Proposed, 구현·실행 검증 미착수

## Objective

실제 스피커·마이크·로컬 모델·Lemmy의 전체 요구사항과 초기 품질 목표 검증.

## Context

문서·fake provider·헤드셋 성공은 로봇 환경의 반향·지연·업무 정합성 증거 아님.

## Scope

- 모델·장치·revision·거리·음량·배경 소음 조건 고정
- 외부 통신 차단 후 대화·메모·알림 전체 시나리오 수행
- 일반 대화·끼어들기 각 100회 및 p50/p95/실패 계측
- 30분 soak·10분 자체 재생 반향·거짓 끼어들기 측정
- GPU 부족·장치 제거·도구 timeout·재연결·재시작 시험
- 기존 Lemmy 경로 복귀·자원 회수·개인정보 로그 검사
- 지원 범위·미달 지표·남은 위험·재현 절차와 릴리스 조건 갱신

## Out of Scope

- 여러 사용자 동시 음성·음성 모델 최초 학습·GPT 수준 품질 동등성 주장

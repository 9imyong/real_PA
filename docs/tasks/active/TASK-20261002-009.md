# 작업: 클라이언트 라우팅 도구 호출

## Objective

- Lemmy 연결에서 8B가 검색·유튜브·날씨·뉴스 도구를 호출하고 결과로 답변
- 턴별 도구 선택은 클라이언트 라우터, 실행은 클라이언트 소유

## Context

- 현재 `/v1/realtime`은 도구 없음, Lemmy는 도구 플래그 사용 시 연결 거절
- 8B 사전 시험(2026-10-02, llama.cpp 18181): 명시 요청 호출, 간접 요청은 단일 도구·required일 때만 호출
- 결정: [ADR-0008](../../decisions/ADR-0008-client-routed-tools.md)

## Scope

- start의 `tools` 정의 등록·`route_request`/`route`·`tool_call`/`tool_result` 메시지
- 세션 LLM 경로의 턴별 도구 부분집합·`tool_choice` 전달, chat_http의 `tool_choice` 지원
- 응답 시한·취소·끼어들기 시 대기 해제, fixture 계약 시험
- 실제 8B로 도구 왕복 시험

## Out of Scope

- 라우터 구현(Lemmy 담당), Lemmy 업무 도구 실행
- 쓰기 도구(메모·알림)의 멱등 처리 변경

## Requirements

- [REQ-API-001](../../requirements/REQ-API-001.md), [ADR-0003](../../decisions/ADR-0003-lemmy-boundary.md)

## Implementation Plan

1. 전송 계약 초안: [duplex-transport](../../specs/duplex-transport.md) 클라이언트 도구 절
2. gateway: start `tools`·`route` 옵션 검증, 수신 메시지 라우팅
3. session: 발화 확정 후 route 대기, 받은 도구로 ToolLoop 구성, 실행은 클라이언트 왕복
4. chat_http: `tool_choice` 전달, manifest `tools` feature 확인
5. fixture 시험 → 실제 8B 왕복 시험
